# Badge

A one- or two-word uppercase pill label on product cards.

- `neutral` (default): `bone-deep` fill, `cafe-noir` text — "린넨", "재입고" (Linen, Restocked).
- `accent`: `kombu-accent` fill, white `on-primary` text (7.0:1) — "신상" (New).
- `primary`: `kombu-green` fill, white `on-primary` text (11.0:1) — "세일" (Sale). One per card at most.
- Korean badges drop the uppercase tracking automatically (`:lang(ko)`, so set `lang="ko"` on the page); keep them to 2–3 syllables.
- Consumer provides the text and `tone`.
