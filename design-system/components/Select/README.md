# Select

Variant picker filled with `kombu-green` and white `on-primary` text and arrow, 5px corners.

- Use for size and colour variants on a product page and for sort order on collection pages ("사이즈: M", "추천순", "낮은 가격순", "높은 가격순", "신상품순").
- Hover fills `kombu-green-hover`. Focus: 2px `focus-ring` outline, 2px offset.
- Consumer provides `options` (strings or `{value, label}`), `value` / `onChange`.
